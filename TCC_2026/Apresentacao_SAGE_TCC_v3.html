1Introdução

Contexto e motivação

O Colégio tem mais de seis décadas de história e milhares de prontuários em arquivos de papel. Digitalizar com método é urgente para garantir segurança dos documentos, conformidade legal e rapidez no atendimento.

Como era

  • Papel sujeito a mofo, traça e extravio
  • Busca lenta em gavetas e arquivos
  • Sem registro de quem consultou ou alterou
  • Nenhuma cópia de segurança das fichas

Proposta do SAGE

  • Prontuário 100% digital, com anexos
  • Busca instantânea por nome, CPF ou responsável
  • Registro permanente de auditoria (LGPD)
  • Relatórios em PDF e CSV com um clique

Trigger de integridadeMySQL 8
-- Bloqueia a exclusão do último administrador
CREATE TRIGGER tr_users_before_delete
BEFORE DELETE ON users
FOR EACH ROW BEGIN
  DECLARE admin_count INT;
  SELECT COUNT(*) INTO admin_count
    FROM users
    WHERE role = 'admin' AND is_active = 1;

  IF OLD.role = 'admin' AND admin_count <= 1 THEN
    SIGNAL SQLSTATE '45000'
    SET MESSAGE_TEXT =
      'Operação cancelada: último admin.';
  END IF;
END;

  // Sem SQL Injection: consulta preparada
  $stmt = $db->prepare(
    "INSERT INTO students (nome, cpf, email)

  );
  $stmt->execute([':nome' => trim($data->nome),
    ':cpf' => trim($data->cpf), ':email' => trim($data->email)]);
}

6Segurança

Upload blindado e documentos protegidos

Tipo real do arquivo

Extensão forjada não passa. O PHP lê os primeiros bytes com finfo_file() e só libera PDF, PNG ou JPG.

Bloqueia .php e .exe

Nome aleatório em disco

Cada arquivo é salvo com random_bytes(16). Ninguém adivinha o endereço do documento de outro aluno.

8fbc4e29b10…pdf

Pasta isolada

O .htaccess nega acesso direto pela web (Require all denied). Só abre com sessão válida.

Sem vazamento pela web
